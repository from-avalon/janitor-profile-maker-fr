A quick guide to the studio.

Start here
  1. Set a preview width.
  2. Choose a preset, template, or edit the code.

About Me

JanitorAI themes live in your About Me field. It can contain HTML and <style>; copy the entire editor, not only the CSS.

Layouts & styles

Profile layouts are built from your Profile information, so importing your profile fills them in. Community templates can be added whole or one part at a time; anything a part depends on comes with it.

Preview & rules

The preview uses captured JanitorAI markup. Keep “Enforce JAI rules” on to see what JanitorAI will keep; blocked code is listed below the editor.

Using your profile

Open your JanitorAI profile, press Ctrl + S, and save it as Webpage, Single File (.mhtml). Import that file from the Profile or Settings tab; it fills in your Profile information and stays in your browser.

Need help?

For help or bug reports, message eslezer on Discord. A screenshot and a copy of the warning below the editor help pinpoint the issue.
