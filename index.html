Working on the canvas

Click selects. Double-click retypes text. Drag one of your own elements to move it; a line shows where it will land. The corner handles resize. Right-click to add something exactly there, or for everything else.

Drag one of JanitorAI's elements — the avatar, the Follow button, a badge — to slide it somewhere else; Alt+drag does the same to your own. Shift keeps the slide straight, Esc cancels it, and right-click → Reset position puts it back.

Something stuck under something else? Click the thing on top, then click the same spot again (or double-click): the selection moves to what is underneath, and it can be dragged out from there. Right-click → Select lists everything under the pointer.

Images have to be online: drag one in from another tab, paste its link, or add an Image and paste the address on the right.

Del removes, Ctrl+D duplicates, Alt+↑/↓ reorders, Esc selects the parent, Ctrl+Z undoes.

Switch to Preview (top bar) when you want links, hover and CSS-only menus to behave like the real page.

About Me

JanitorAI themes live in your About Me field. It can contain HTML and <style>; the studio writes both for you. Code in the top bar shows the document — copy all of it, not only the CSS.

Sections, styles & animations

All under Insert. Sections are pieces of whole profile designs: drag one onto the canvas, or add a design whole; anything a piece depends on comes with it. Styles apply to the whole profile. Animations apply to whatever is selected.

Layouts built from your Profile data keep themselves up to date with it. Edit one by hand on the canvas and it is unlinked, so your changes stay — Ctrl+Z links it back.

Preview & rules

The preview uses captured JanitorAI markup. Keep “Enforce JAI rules” on to see what JanitorAI will keep; anything blocked is listed in the status bar and beside the code.

Using your profile

Open your JanitorAI profile, press Ctrl + S, and save it as Webpage, Single File (.mhtml). Import that file from the Profile data panel, or from the Page panel on the right when nothing is selected; it stays in your browser.

A saved page only holds the characters that were on it. If your list runs to several pages, open page 2, 3… on JanitorAI, save each the same way, and press Add more pages in Profile data — you can pick them all at once.
